## 6. Judging criteria, judges, demo rules

- **Judging criteria and weights (published):**
  1. Usefulness on G2 · 30% — solves a real moment, glanceable and hands-free — https://dorahacks.io/hackathon/even-realities/detail
  2. Read and write · 25% — users don't just see information, they act on it; writing is fast: a short phrase, one tap or the ring, with smart defaults or AI drafts instead of long dictation — https://dorahacks.io/hackathon/even-realities/detail
  3. Technical execution · 20% — works end to end, reliable, clean code — https://dorahacks.io/hackathon/even-realities/detail
  4. UX for display and voice · 15% — clear on a 576 × 288 monochrome display, natural by voice — https://dorahacks.io/hackathon/even-realities/detail
  5. Business potential and safety · 10% — real users and demand, careful with data and money — https://dorahacks.io/hackathon/even-realities/detail
- **Who judges:** "Judges come from Even Realities, TVM Ventures, partner venture funds, sponsors and Daos Hub." (No individual judge names published on the page.) — https://dorahacks.io/hackathon/even-realities/detail

## 8. Constraints on an AI-agent-built entry

- **Must be built during the hackathon:** "Build during the hackathon. Open-source libraries and existing APIs are allowed; say in your README what existed before Nov 23." — https://dorahacks.io/hackathon/even-realities/detail
  - Pre-built repos are therefore NOT disallowed outright, but pre-Nov-23 work must be disclosed in the README, and only the listed open-source libraries / existing APIs are explicitly allowed as pre-existing material — https://dorahacks.io/hackathon/even-realities/detail
- **AI-agent / AI-tool use is NOT addressed on the page:** no rule bans or requires disclosure of AI-generated code; the only disclosure rule is the pre-existing-work README note above — https://dorahacks.io/hackathon/even-realities/detail
- **Track restriction:** "Use only the apps listed in your track." — https://dorahacks.io/hackathon/even-realities/detail
- **Third-party terms & privacy:** "Respect the terms of the services you integrate and the privacy of the people whose messages you show." — https://dorahacks.io/hackathon/even-realities/detail
- **Disqualification:** "Organizers may disqualify projects that break these rules or the DoraHacks terms." — https://dorahacks.io/hackathon/even-realities/detail
- **Technical constraints (from "Build for G2"):**
  - App is a web app (HTML, CSS, JavaScript or TypeScript) running in a WebView inside the Even Realities App, talking to G2 over Bluetooth through the Even Hub SDK — https://dorahacks.io/hackathon/even-realities/detail
  - Display: monochrome green, 576 × 288 per eye; input: microphone, touch controls, R1 ring; no camera, no speaker on the glasses — https://dorahacks.io/hackathon/even-realities/detail
  - One app on screen at a time; when the user switches away it cannot show anything or pop up alerts — https://dorahacks.io/hackathon/even-realities/detail
  - No access to other apps' notifications — talk to the service directly through its API — https://dorahacks.io/hackathon/even-realities/detail
  - Bring your own speech-to-text — the SDK gives raw microphone audio (send to your own server, e.g. Whisper) — https://dorahacks.io/hackathon/even-realities/detail
  - Use a backend — external calls must be whitelisted in `app.json` and pass CORS; route API calls through your own server and never ship API keys inside the app — https://dorahacks.io/hackathon/even-realities/detail
  - Sign-in: Google sign-in does not work inside the WebView — use a separate login page or a pairing code — https://dorahacks.io/hackathon/even-realities/detail
  - Design for a glance: one thing on screen, a few words, one action by tap, ring or a short phrase — https://dorahacks.io/hackathon/even-realities/detail
- **Setup (from page):** read the Even Hub docs; `npm install -g @evenrealities/evenhub-cli` and `npm install -g @evenrealities/evenhub-simulator`; start from the official minimal template and point the simulator at the local dev server — https://dorahacks.io/hackathon/even-realities/detail
  - Even Hub docs (found via web search, NOT linked with a URL in the fetched page text): https://hub.evenrealities.com/docs/get-started/quickstart/first-app and simulator docs https://hub.evenrealities.com/docs/test/simulator
